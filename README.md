# IEICE SeMI Website

電子情報通信学会 センサネットワークとモバイルインテリジェンス研究専門委員会（SeMI）のWebサイトリポジトリです。

- 公開URL: https://ieice-semi.org/


## 研究会を追加する

1. `docs/_posts/YYYY-MM-DD-conf.md` を作成する（過去の`.md`ファイルをコピーするのが楽）
2. メタ情報（`.md`ファイルの冒頭6行）を編集する（これによってURLやページタイトルが決まります）
3. 本文を作成する


## お知らせを更新する

`docs/_posts/2000-01-01-announce.md` を更新してください。


## その他の固定ページを編集する

- 各ページごとにファイルが分かれています（`docs/XXX.md`）ので、対応するファイルを編集してください。


## ローカルで編集内容を確認する

Ruby の環境が必要ですので、いい感じに準備してください。

```
cd docs/
bundle exec jekyll serve
```

- http://127.0.0.1:4000/ で、編集内容が確認できます（たぶん）

## 注意点

- `docs/_site/` のフォルダ内は、ローカル確認用に自動生成されるファイル群が格納されています。ここを直接編集しても意味がないです。
